03 · How it works

A router, one lead, specialists only when they matter.

Firmcraft is a set of instructions your assistant reads, not a hosted service. It loads only what a request needs.

Route the job

A known workflow loads its lead persona directly. Other requests use the relevant practice index.

Set the scope

Uses available company context, names the decisive gaps and picks a depth: brief, standard or deep.

Analyze the evidence

Findings link to source locations, calculations and criteria. Assumptions and contradictions stay visible.

Bring in specialists

Extra personas answer bounded, material questions. Separate agent runs depend on your host tool.

Deliver once

The lead consolidates one artifact with actions and the evidence that would show each is done.

Review and update

Technical soundness and request fulfillment are judged separately. Follow-ups keep finding IDs.

Pass

The assessed axis meets the stated criteria within the evidence and scope used.

Provisional

Useful work exists, but named assumptions, gaps or verification remain.

Blocked

A missing fact or conflicting requirement prevents the requested conclusion.

These are instructions for the model, not a deterministic workflow engine. There is no ERP connector, document editor or hosted portal. Outputs are AI drafts and never replace professional sign-off.

05 · Install

Pick your assistant. Paste a few lines.

No account or API key for Firmcraft itself. An assistant that can read the installed files is required; a plain chat window does not gain these capabilities.

1 · Add the marketplace, then install
/plugin marketplace add Lameda12/Firmcraft-skill
/plugin install senior-consulting-agents@senior-consulting-agents
2 · Try a workflow in a new session
/senior-consulting-agents:management-report

Prepare a brief October management report for a 40-person B2B distributor.
Audience: owner and finance lead. All amounts are CAD thousands.

Supplied finance table:
Metric            Actual    Budget
Revenue           120       100
Operating costs    90        80
Operating profit   30        20

Supplied cash table:
Opening cash: 40
Net cash movement: -15
Reported closing cash: 30

Calculate the variances and reconcile cash. Do not invent causes for
unexplained movements. Return a decision summary, editable tables,
evidence gaps and three prioritized actions with proposed owners.
Use only these supplied figures; mark missing context explicitly.

Choose both skills

Select senior-consulting-agents and consulting-deliverable-standards, then your assistant.

The portable route ships workflows as reference files. It does not register the 13 slash commands in other assistants. Needs Node.js for npx.

1 · Copy both skill folders from a checkout (macOS/Linux)
git clone https://github.com/Lameda12/Firmcraft-skill
cd Firmcraft-skill
mkdir -p "$HOME/.agents/skills"
cp -R skills/senior-consulting-agents "$HOME/.agents/skills/"
cp -R skills/consulting-deliverable-standards "$HOME/.agents/skills/"
2 · In a new Codex session, select the skill with $
$senior-consulting-agents

Use the management-report workflow in brief mode for a 40-person B2B distributor. Audience: owner and finance lead. Period: October. All amounts are CAD thousands.

Team-wide install

Place both complete skill directories under .agents/skills/ in the target project instead of your user directory. Keep all nested references, and avoid installing the same skill at several scopes.

Install the repository as a Gemini CLI extension
gemini extensions install https://github.com/Lameda12/Firmcraft-skill

What the repo provides

The repository includes gemini-extension.json and a GEMINI.md context file that points Gemini to the router skill. Features and invocation differ by host, and this route has not been tested end to end for this page.

Put these files in the model's context
skills/senior-consulting-agents/references/agents/<persona>.md
skills/senior-consulting-agents/references/deliverable-standards.md
skills/senior-consulting-agents/references/engagement-method.md
skills/senior-consulting-agents/references/workflows/<workflow>.md

For models without a skills system

Paste the actual file contents, not just paths, then add your request and evidence. Calculations and verification still depend on the tools that model has.

A note on names

Firmcraft is the product name. The installed identifiers have not changed, so use these exactly. /firmcraft:… and $firmcraft are not registered.
