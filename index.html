01 / INSTALL

Pick your tool. Paste one line.

No account, no API key, no signup form. The skills are plain Markdown files your agent reads when a request needs them.

Run in your terminal
$ npx skills add Lameda12/senior-consulting-agents
Then just ask your agent
# the router skill picks the right 1-3 personas
Draft an audit planning memo for a Canadian SaaS company with $40M ARR

Works with anything that supports Agent Skills

  • Codex CLI, Gemini CLI, OpenCode
  • Cursor, Cline, GitHub Copilot
  • Claude Code (skills only; use the plugin tab for subagents and commands)

Needs Node.js 18+ for npx.

1 · Inside Claude Code, add the marketplace
> /plugin marketplace add Lameda12/senior-consulting-agents
2 · Install the plugin
> /plugin install senior-consulting-agents@senior-consulting-agents
3 · Run an engagement
> /engage Canadian SaaS company (ARR $40M) preparing for US IPO: revenue recognition, SOX readiness and Pillar Two exposure

The full experience

  • 54 real subagents that can work in parallel
  • 11 slash commands like /engage and /review
  • 2 skills: the router and the house style

Working from a clone? claude --plugin-dir ./senior-consulting-agents

Install as a Gemini CLI extension
$ gemini extensions install https://github.com/Lameda12/senior-consulting-agents
Then ask
Run a cyber maturity assessment for a mid-size credit union

What you get

The extension ships the skills plus a GEMINI.md context file, so Gemini knows which persona to load for each request.

Clone and copy the two skill folders
$ git clone https://github.com/Lameda12/senior-consulting-agents
$ cp -r senior-consulting-agents/skills/* ~/.claude/skills/

Skills directory per tool

Claude Code~/.claude/skills/
Codex CLI~/.codex/skills/ or .agents/skills/
Gemini CLI~/.gemini/skills/
OpenCode~/.config/opencode/skills/
Grab any persona as a system prompt
$ curl -sL https://raw.githubusercontent.com/Lameda12/senior-consulting-agents/main/skills/senior-consulting-agents/references/agents/strategy-director.md
Optional: append the house style
$ curl -sL https://raw.githubusercontent.com/Lameda12/senior-consulting-agents/main/skills/senior-consulting-agents/references/deliverable-standards.md

For models without a skills system

DeepSeek, Llama, Nemotron, local models in Ollama or LM Studio, or any chat UI. Paste the persona file as the system prompt. Swap strategy-director for any id in the agent list.

02 / HOW IT WORKS

Structured problem-solving, minus the billable hours.

A router skill indexes every persona and workflow, then loads only the 1-3 files a request actually needs. Your context window stays small. The arguing stays efficient.

1

Route

Your request is matched to a workflow: audit plan, tax memo, due diligence, valuation and more.

2

Staff

The best 1-3 senior personas are pulled in by practice, jurisdiction and topic.

3

Argue

Each persona applies its own frameworks. Subagent-capable tools run them in parallel.

4

Deliver

One consolidated, partner-reviewed-style deliverable in a consistent house style.

03 / COMMANDS

Eleven engagements, one slash away.

Slash commands in the Claude Code plugin. In every other tool, just describe the task in plain words. Click any card to copy it.

04 / THE BENCH

54 seniors. Zero juniors to blame.

Managers, Senior Managers, Directors and Partners across every major practice. Click an agent to copy its id.
